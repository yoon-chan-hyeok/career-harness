# v3 첫 증분: 경험 읽기 모델과 실행 없는 계획 미리보기

기준 커밋은 `4202b86c079df28642e24e01d420664600bad316`이다. 사용자가 2026-10-22에 구현 시작과 GitHub 버전 관리 협업을 요청했다. 작업 브랜치는 `codex/v3-experience-shadow`이며 변경은 PR에서 검토한다. 이번 증분을 운영에 자동 배포하거나 main에 자동 병합하지 않는다.

## 범위

- ExperienceCard는 기존 Evidence/Source/DecisionEpisode/Ownership/Metric/ClaimBoundary를 읽는 projection이다. 새 사실 저장소를 만들지 않는다.
- RoleInterpretationProposal과 SectionTrace는 후속 구현의 데이터 계약이다. 직무 해석 생성·Persona 선택·문단 수정 UI를 완성한 상태로 표시하지 않는다.
- 규칙 선택/전달과 검사 결과를 구분한다. 기존 문장에 실제 기록 없는 규칙 적용 이력을 만들어 붙이지 않는다.
- ContextBudget은 입력과 출력 예약을 합한 정적 한도 계약이다. 실제 모델 요청을 아직 조립하지 못한 경로는 NOT_ESTIMATED로 두며 비용·공급자 가용량·전체 입력 문제 해결을 주장하지 않는다.
- 새 미리보기는 기존 작성 실행기와 분리한다. DB 변경, 모델 호출, 승인, 잠금, 제출은 수행하지 않는다. 기존 결과는 재사용 후보일 뿐 완료 증명이 아니다.
- 9권 전체 원문·246 규칙은 이번 첨부 ZIP에 없었다. 새 규칙을 가져오거나 활성화하지 않는다. 개인 첨부 자료·실제 지원서·키는 공개하지 않는다.

## 다음 증분과 변경 수용

이 브랜치의 계약과 경계 검사를 먼저 확정하고, 이후 사용자 변경 자료에 맞춰 확장한다. 다음 작업은 실제 요청의 단계별 Context Compiler와 원문 버전 연결, Persona 선택 및 문항 하나의 생성·검수·설명 흐름이다. 새 엔진의 실행 어댑터는 기존 ready/freeze/confirm_submission 검증을 반드시 재사용한다. 비교·성능 개선 실험은 기존 사용자 결정대로 범위에 추가하지 않는다.

## 롤백

아직 운영 미반영이므로 이 PR을 병합하지 않으면 현재 서비스에는 변화가 없다. 이후 병합해도 미리보기 기능 설정을 끄면 새 경로를 닫을 수 있게 한다. DB 마이그레이션 없이 추가하며, 이미 공유한 커밋은 삭제하거나 강제로 덮어쓰지 않고 필요한 커밋을 revert한다. 기준 커밋으로의 hard reset을 운영 롤백 절차로 사용하지 않는다.
