작성전략의 Reverse Test / Red Team 대응을 자소서와 이력서의 화면·대화·보관함·제출본 기반 면접 자료까지 연결했다. 아래 합성 검증은 통과했다. **문서 전체 절차와 실제 AI·외부 운영 인수는 아직 완료되지 않았다.** 기존 `RULEBOOK_V5_1_RECHECK_2026_10_07.md`의 F8 화면·대화·이력서 규칙·면접 연결 누락은 이 기록으로 갱신한다. 그 보고서의 조사·표현 재사용·최종 제출 판단 누락은 여전히 남는다.

## 구현한 흐름

- 검수 질문마다 답변·이유·처리 방법·원문 인용을 입력한다. 일부 질문만 먼저 저장할 수 있고, 미답변이 남으면 최종 잠금을 차단한다.
- 사실 확인은 현재 선택한 근거의 정확한 원문 인용으로 대조한다. 면접 준비나 공백 인정으로 사실 문제를 우회할 수 없다. 중대한 채용 위험도 답변만으로 면제하지 않는다.
- 직접 대조한 답변은 명시적 확인을 요구한다. AI 확인은 별도 판정을 저장한다. 대화에서 추출한 답변은 이번 사용자의 실제 입력에 포함된 문자열만 허용하며 승인이나 사실 등록을 대신하지 않는다.
- 문서 수정·근거 보완은 계획으로 남는다. 기존 수정 제안 승인과 새 버전 재검수를 거쳐야 한다. 기존 원문을 보존하고 이전 검수 답변은 재검토 대상으로 바뀐다.
- 답변은 해당 문서·검수 버전에 묶인다. 잠근 뒤 답변을 바꾸면 다시 명시적으로 잠가야 한다.
- 이력서의 역질문·답변 추출·답변 검증·면접 자료는 Resume 규칙 묶음을 사용한다.
- 제출 보관본에 잠긴 답변을 보존하고, 면접 자료는 그 보관본에 포함된 답변을 읽는다. 답변을 Career Truth로 승격하지 않는다. 동결은 실제 제출과 계속 구별한다.
- 늦게 나타난 입력칸 때문에 저장 후에도 이동 경고가 남던 편집창 오류를 수정했다. 저장하지 않은 다른 양식의 실제 변경은 보호한다.
