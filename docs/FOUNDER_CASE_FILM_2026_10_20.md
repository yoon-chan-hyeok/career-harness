# 실제 제작 사례 숏폼 — 2026-10-20

Career Harness를 만들게 된 실제 문제 두 가지와 연구 경험의 문항 메시지를 보여 주는 38초 세로 모션그래픽이다. 사용자가 제공한 자기소개서에 서술된 제작·연구 경험과 현재 공개 구현을 대조했다. 개인 지원서 원문과 모델의 원래 대화·응답을 영상이나 저장소에 복사하지 않았다.

## 실제 사례와 재구성의 범위

| 실제로 서술한 문제 | 바꾼 판단 | 영상에서 보여 주는 장면 |
|---|---|---|
| LLM이 기술 키워드가 겹친다는 이유로 실제 업무가 다른 직무까지 적합하다고 판단 | 실제 업무·직접 증명할 경험·부족한 역량을 먼저 본다 | 공고와 경험의 RAG를 연결한 뒤, 판단 기준 세 가지로 전환 |
| 작성 중 경험의 범위·수치·본인 기여가 바뀌는 문제 발견 | Fact와 Expression 분리, 주장과 근거 연결, 사실·채용 관점 검토, 사용자 승인 | 경험 범위·수치·기여가 흔들리는 장면 → 사실/표현 분리 → 검수 역할 → 승인 |
| Multi-Agent 실패 진단 연구에서 여러 탐색 방식을 시도한 뒤, 성공 조건을 먼저 정의하고 로그에서 실패 지점을 추적하는 접근으로 전환 | 도전 문항에는 사용한 기술 목록보다 관점을 바꾼 이유와 실제 행동을 보여 준다 | Chunking·Search·Reranking 나열 → 관점을 바꾼 이유 → 성공 조건과 로그 진단. 편집한 메시지 예시이며 앱의 AI 생성 결과가 아님 |

이는 제작자가 실제 경험으로 설명한 사건의 재구성이다. 원래 모델 응답이나 특정 채용공고를 그대로 재현한 녹화가 아니다. 성능·합격률·시간 절감 수치는 제시하지 않는다. Multi-Agent 연구의 수치나 논문 성과를 Career Harness의 성과로 옮기지 않았다.

문항별 작성 설계와 오른쪽 보관함은 [실제 공개 구현·인수 기록](WRITING_PLAN_2026_10_17.md)에 근거한다. 제품 화면은 실제 앱에서 합성 QA 자료로 촬영한 이미지이며, 개인 경험이나 실제 AI 생성 결과를 보여 주지 않는다. 600자 70/120/280/130은 [등록된 원문 가이드](../backend/career/assets/writing_guides/posco_dx_technical.json)의 내용별 권장 배분으로 한정한다.

## 구성

| 시간 | 장면과 모션 |
|---|---|
| 00–02 | “AI가 내 경력을 바꿨다” 큰 타이포의 순차 진입, 직무·수치·기여 태그 |
| 02–04 | 두 RAG의 연결과 키워드 매칭 문제 |
| 04–07 | 실제 업무·직접 경험·공백 세 가지 기준, 선을 따라 이동하는 포인터 |
| 07–09.5 | 경험 범위·성과 수치·본인 기여의 흔들림과 확인 필요 표시 |
| 09.5–12 | 사실/표현 분리, 주요 주장과 근거를 잇는 흐름 |
| 12–15 | 작성·사실 검수·채용 관점 검토의 역할 연결, 이동하는 입자 |
| 15–18 | 사용자 승인 버튼, 커서 이동·클릭·상태 전환의 시각적 재구성 |
| 18–23 | 실제 작성 설계 화면의 확대와 오른쪽 보관함 이동 |
| 23–27 | 실제 연구 경험을 기술 나열에서 판단 전환으로 재구성 |
| 27–30.5 | 600자 권장 배분의 숫자·막대 애니메이션 |
| 30.5–34 | 흩어진 판단 요소가 Skill·Rule 중심으로 연결 |
| 34–38 | Career Harness 로고·공개 체험 안내 |

한국어 핵심 자막을 화면에 넣고 SRT도 제공한다. 144 BPM 비트·짧은 전환음·클릭 시점의 액센트는 외부 음원 없이 직접 합성했다. 단순 반복 카드 대신 장면별 도형·연결선·입자·커서·제품 화면을 시간에 따라 그린다. 1080×1920, 60fps, H.264/AAC stereo, faststart MP4다.
