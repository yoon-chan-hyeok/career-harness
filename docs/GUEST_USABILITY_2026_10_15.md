# 공개 체험 사용성 보완 — 2026-10-15

사용자가 추가 구현과 페이지 완성도를 확인해 달라고 요청했다. 기존 공개 무료 체험의 동작을 유지하며, 처음 시작할 때의 안내와 자료 보관 경로를 보완한다.

## 변경

- 체험 작업실과 시작 안내에 남은 연결 시간을 표시한다. 종료 1시간 전부터 보관 안내를 강조한다. 시간은 브라우저 안내값이며 서버의 서명·만료·철회 검사를 대체하지 않는다.
- 같은 안내에서 자기 자료 전체 JSON을 내려받을 수 있다. 기존 설정·로컬 내보내기와 다운로드 처리를 공유한다. 자동 복구나 새 작업실로 가져오기 기능으로 표현하지 않는다.
- 이미 만료되었거나 30초 이내 종료되는 저장 연결을 다시 시작하도록 제안하지 않는다. 만료된 게스트에게 이메일 갱신 요청을 보내지 않는다.
- 빈 작업실에 경험 정리 → 공고 추가 → 대화·보관함의 세 단계를 안내하고, 경험/공고 시작 버튼을 제공한다.
- 개인정보·약관 페이지의 돌아가기 경로를 실제 `/workspace`로 수정한다. 승인받은 문의 이메일을 그대로 표시하고 모바일 시작 링크를 다시 노출한다.
