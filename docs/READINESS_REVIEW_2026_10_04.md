# 추가 작업과 업그레이드 확인

2026-10-04 최신 코드·검사·현재 로컬 런타임 기준. 핵심 작성 기능과 캐시 개선은 로컬에서 검증됐다. 실제 AI·운영 계정·HTTPS 인수는 남아 있으며 전체 서비스 완료로 표시하지 않는다.

## 현재 확인된 상태

18:13 KST 로컬 관측에서 화면, health, readiness, 현재 계정 관리자, 새 사용량 API가 모두 HTTP 200이었다. 인증된 기존 소유자를 유지했고 합성 검증 토큰의 접근은 401이었다. 운영 중인 로컬 DB는 SQLite이며 AI 제공자는 `none`, configured/live_verified는 false다. 새 cache API는 현재 로컬 서버에 반영됐다. 근거: 비공개 `work/kv-normal-runtime.json`.

18:12~18:15 KST 외부 읽기 조회도 확인했다. Supabase 커넥터에서 접근 가능한 조직 1개·프로젝트 0개, Vercel 커넥터의 접근 가능한 팀·프로젝트 목록 각각 0개였다. 프로젝트 전용 Vercel CLI 설정은 로그아웃이며 로컬 프로젝트 연결 파일도 없었다. 커넥터 목록 0개는 계정 전체에 프로젝트가 없다는 증명이 아니다. 기본 전역 CLI는 설정 디렉터리 권한 제약으로 미확인이다. HF 커넥터는 인증됐지만 OAuth 권한에 앱 추론 호출 권한이 없었다. 이번 조회에서 프로젝트 생성·로그인 변경·배포·유료 호출은 하지 않았다.

## 이미 구현된 항목

- 중앙 대화창·오른쪽 문서 보관함, 경험 정리, 자소서와 레쥬메 작성·검수·승인·버전 저장.
- 레쥬메 1/2/MASTER 분량, 확인된 경험 최대 3안 선택과 작성 반영, 선택 변경 시 이전 문서 재검토.
- 문장별 근거, 미저장 편집 보호·복구, PDF/DOCX, 파일 가져오기, 한국어 E5 의미 검색·근거 매핑.
- 일·월 사용 상한, 전체 요청 시간 제한, 무료 제공자 입력 제한, 자동 유료 fallback 차단, 개인정보 소스 제외.
- 관리자 화면과 실제 실행 기록에 연결한 여섯 역할 작업실. 역할은 중앙 워크플로가 제어하며 일부 검수 호출이 병렬이다.
- 캐시용 입력 배치 안정화, 불투명 사용자 구분, 실제 reported token만의 재사용률 표시. 잘못된 수치의 저장 후 집계, UTC 일·월 경계, 미확인 비용과 최대 예약의 구분도 수정됐다. 상세: [캐시 개선](PROMPT_CACHE_UPGRADE.md).

MCP는 로컬 stdio의 읽기 도구 3개(profile/evidence/submission)다. 원격 ChatGPT 연결과 쓰기·승인 MCP까지 개발됐다고 표현하지 않는다. Jev는 선택적 shadow 어댑터·기록이 있으며 실제 응답은 미확인이다. 무료 제공자 대화의 기본 검색은 어휘 검색이다. E5 검색·명시적 근거 매핑이 있다고 모든 대화에서 의미 검색을 사용한다고 표현하지 않는다.

마감 문제는 실제 `rankings()` 함수를 합성 메모리 자료로 실행해 재현했다. 이미 마감된 HIGH/PROCEED 항목이 미래 마감 LOW/PROCEED보다 앞에 남았다. 실제 개인 DB나 화면 자료를 변경한 재현은 아니다. 근거는 `backend/career/assessment.py`의 평가 시점 만료 판단과 조회 시 저장 추천 사용, `frontend/app/review-controls.tsx`의 표시다. 이번 캐시 수정에 이 별도 보완은 포함하지 않았다.

HF 토큰은 채팅에 보내지 않고 앱 설정의 ‘AI 연결’에 입력한다. HF 커넥터 로그인은 앱 추론 토큰과 다르다. 무료 계정의 실제 잔액·청구 설정·제공자 한도를 확인하며 유료 플랜·크레딧 구매·유료 자동 전환은 요청 범위에 없다.

기존 GitHub 신규 비공개 저장소 생성·소스 업로드는 자동 승인 검토가 정확한 목적지와 업로드 대상의 명시적 승인 부족으로 거절해 미실행 상태다. 새 cache 변경 때문에 기존 검토 ZIP도 최신 소스가 아니다. 이번 점검에서는 업로드를 시도하지 않았다.

## 선택적 업그레이드

1. 관리자 실패 항목에서 해당 지원·실행·문서 버전·복구 위치로 이동. 현재는 실행 요약이다.
2. 지원·근거·오래된 문서 버전 목록의 페이지 분할. 의미 검색 목록의 기존 페이지 분할과 구별한다.
3. 필요하면 HF/Groq 자연어 대화에서 무료 의미 검색 연동 확대. 현재 E5 검색·명시적 매핑은 이미 있다.
4. 실서비스 인수 후 합성 사례로 설계 의도·사실/표현 분리·RAG·Jev 경계를 설명하는 포트폴리오. 사용자가 이후 작업으로 지정했다.
5. ChatGPT에서 자료를 원격 조회할 필요가 생길 때 인증된 HTTP MCP. 현재 출시 필수 조건은 아니다.

과거 보고서의 ‘지원 기회 우선순위 컴포넌트 미연결’은 정정한다. `OpportunityRankings`는 이미 지원 기회 화면에 연결되어 있다. 추가 보완은 현재 시각의 마감 상태다. 이전 필수 보완 4건과 업그레이드 6종도 이미 구현돼 신규 할 일로 반복하지 않는다. 모델 비교·개선 입증 실험과 자유로운 자율 에이전트 토론은 제외 상태를 유지한다.
