# 현재 사용자 결정 — 2026-10-02

이 기록은 원래 구현 팩보다 나중에 사용자가 직접 정한 범위다. 충돌하면 아래 결정을 우선한다.

- 목표는 본인이 실제 사용하는 취업 서비스이자 개인 포트폴리오다.
- 자소서뿐 아니라 레쥬메 작성·검토·저장 흐름도 이번 서비스 범위에 포함한다.
- B0/B1/B2/B3 비교, 성능 향상 입증, 개선/업그레이드 실험과 그 실험 결과를 만드는 작업은 이번 범위에서 제외한다. 기존 평가 코드는 보존하되 출시를 막는 조건으로 사용하지 않는다.
- 기능 정확성, 사실/출처/본인 기여 검증, 인증·데이터 격리, 장애 처리, 백업/복구를 확인하는 검사는 계속 필요하다.
- 설계 의도·RAG·Jev 설명과 공개 포트폴리오 페이지는 이후 작업이다.
- 무료 제공자와 합법적인 무료 크레딧을 우선 조사해 실제 모델 호출이 되는 서비스를 만든다. 무료 다운로드 모델, 무료 한도, 유료 API를 구분하며 무제한 무료라고 표현하지 않는다.
- 유료 플랜 가입·크레딧 구매·자동 유료 제공자 전환은 이번 요청에 포함되지 않는다. 자격증명과 개인자료를 공개 저장소나 브라우저 번들에 넣지 않는다.
- Hugging Face의 OpenAI 공개 가중치 모델은 OpenAI의 상용 API 모델과 다르다. Jev도 공식 접근 가능 여부를 확인하기 전 연결됐다고 표시하지 않는다.
- 역할별 정보 경계와 승인, 중앙 워크플로 제어를 유지한다. 이번 결정으로 자유로운 자율 에이전트 토론을 추가하지 않는다.
